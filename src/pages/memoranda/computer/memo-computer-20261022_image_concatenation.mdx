複数の画像を連結して一枚の画像にするには，`brew install imagemagick` で [ImageMagick](https://imagemagick.org/) をインストールし，コマンドラインで
```
magick input1.png input2.png -append output.png
```
<p class="no-indent">などとすれば良い．</p>
